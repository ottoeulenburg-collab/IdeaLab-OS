# IdeaLab!-Schrift

Hier kann die reguläre Coolvetica-Schrift als `coolvetica.woff2`, `coolvetica.woff`, `coolvetica.otf` oder `coolvetica.ttf` abgelegt werden. Die App bindet die Datei anschließend automatisch lokal ein. Bei laufendem Entwicklungsserver die Seite danach neu laden; für die Produktionsversion `npm run build` ausführen.

Die Datei muss für die Verwendung als Webfont freigegeben sein. Es wurde keine Coolvetica-Datei heruntergeladen oder mitgeliefert. Bereits auf dem Rechner installierte Coolvetica wird ebenfalls verwendet. Bis die Schrift vorliegt, bleibt die lokal gebündelte DM Sans als Ersatzschrift aktiv.

Originalquelle: https://typodermicfonts.com/coolvetica/
